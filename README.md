# Portfolio V2 preview source

A lightweight static portfolio built with HTML and CSS. No JavaScript framework or package install is required.

## Preview locally

1. Extract this folder.
2. Open `index.html` in a browser, or run `python -m http.server 8000` from this folder.
3. Open `http://localhost:8000`.

The CV download button points to `assets/CV_Zouhair_El_Hadnaoui.pdf`. The source repositories for L9AYTHA and VEGA ERP remain private and are not linked.
